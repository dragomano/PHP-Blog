Herd — это молниеносная, нативная среда разработки на Laravel и PHP для MacOS и Windows. Она включает в себя всё необходимое для начала разработки на Laravel, включая PHP и Nginx. После установки Herd вы будете готовы начать работу с любым современным PHP проектом (на Symfony, Slim, Laravel и т. п.).

16 октября 2026 года вышла Herd 2.0 — самое крупное обновление среды: переработанный интерфейс, отдельное окно приложений, студия для работы с ИИ-агентами (Herd Studio), параллельные воркспейсы, автоматический запуск dev-сервера и развёртывание приложений в Laravel Cloud. Обзор новинок — ниже, полный список изменений — в [changelog](https://herd.laravel.com/changelog).

!!! tip "Совет"

    Ничто нам не мешает создать сайт с Laravel, затем удалить из директории все файлы и заменить их на файлы другого движка. Поэтому Herd пригодится не только Laravel-разработчикам. В документации есть уже целый [список поддерживаемых фреймворков и CMS](https://herd.laravel.com/docs/windows/extending-herd/supported-frameworks).

## Установка

Первым делом [скачиваем файл приложения](https://herd.laravel.com), запускаем и устанавливаем.

Можно настроить путь к файлам сайтов, автозапуск приложения, а также автоматическое обновление.

С помощью интуитивно понятного пользовательского интерфейса вы можете управлять конфигурацией, включая версии PHP, Node.js, и SSL-сертификаты.

Новые сайты создаются с помощью кнопки «Создать» в окне _Приложения_. Для каждого сайта можно выбрать стартовый набор, версию PHP, а также включить/отключить поддержку HTTPS.

В Herd 2.0 приложения переехали в отдельное окно: здесь создаются новые сайты, открываются недавние проекты, а панель выбранного сайта даёт быстрый доступ к терминалу, Tinker, логам, воркспейсам и настройкам окружения.

Приложения теперь тоже можно создавать с помощью ИИ: достаточно указать имя и описать желаемое обычным языком, например «Создай приложение, которое...» — агент соберёт стартовый проект за вас. Останется выбрать модель кодирования и стек (Vue, React, Livewire и т. п.), а в расширенных опциях — версию PHP, базу данных и HTTPS.

## Herd Studio

Главная новинка Herd 2.0 — студия для работы с ИИ-агентами, которую разработчики включили даже в бесплатную версию. На страницах всех локальных `.test` сайтов (не только Laravel) появляется бейдж «Edit with Herd», клик по которому открывает рабочую область прямо в браузере: живой превью сайта рядом с инструментами проекта. Вся студия работает локально, на вашем компьютере.

Внутри есть всё, чтобы вести разработку, не переключаясь между окнами:

- чат с ИИ-агентом, который видит контекст открытой страницы (для каждого сайта можно вести несколько переписок);
- редактор кода проекта с автодополнением для PHP и просмотром всех правок агента в виде диффов;
- клик по любому тексту в превью — агент найдёт его в шаблонах и поправит;
- терминал внутри директории проекта;
- логи приложения и воркер очереди;
- настройки сайта: версия PHP, HTTPS, изоляция, сервисы;
- шаринг сайта через Expose и деплой в Laravel Cloud;
- Tinker и Insights (дампы, запросы, логи, задания и HTTP-вызовы) — эта пара уже только в Herd Pro.

Открыть студию можно и без бейджа: по адресу `https://ваш-сайт.test/herd-studio`, двойным щелчком по сайту в окне приложений или командой `herd studio` в директории проекта. Если приложение выбросило исключение, студия покажет последнюю ошибку и позволит передать её агенту.

Студия не навязывает подписку: подключайте своих агентов (Claude Code, Codex, OpenCode, Cursor и другие) и провайдеров ИИ, а если подписки на нейросети нет, бесплатно начните со встроенных моделей OpenCode. Для голосовых запросов есть диктовка: выбираете язык и модель распознавания речи, модель подгружается при первом использовании.

Все параметры собраны на вкладке «ИИ» в настройках: там включаются значки «Edit with Herd», интеграция Herd с агентами кодирования по MCP, уведомления о завершении работы агента и фоновое обновление инструментов кодирования.

## Параллельные воркспейсы

Ещё одна давно запрошенная возможность. Herd автоматически обнаруживает git worktree и публикует их как поддомены основного сайта — воркспейс ветки `feature-auth` для `shop.test` будет доступен на `feature-auth.shop.test`. Так вы — или несколько ИИ-агентов — можете работать над разными фичами одного приложения одновременно, не переключая ветки и не мешая друг другу.

Воркспейс создаётся командой `herd workspace <имя>` в директории сайта, из панели приложения или прямо из Herd Studio. Проект копируется, для него заводится ветка и отдельный домен, а база данных — на выбор: общая с родителем, клон или чистая с последующими миграциями. Список воркспейсов сайта отображается в панели приложения, где их также можно открыть или удалить.

## Автоматический запуск dev-сервера

Знакомая ситуация: открываете локальный сайт, а там ошибка, потому что воркер очереди или Vite не запущены. Herd 2.0 при обращении к сайту сама запустит `php artisan dev` или `vite`, а состояние всех процессов видно по бейджу Herd Studio.

## Развёртывание в Laravel Cloud

Подключите аккаунт [Laravel Cloud](https://cloud.laravel.com) — и разворачивайте приложения прямо из интерфейса Herd: кнопка «Развернуть в Laravel Cloud» появилась в панели приложения и в инструментах Herd Studio.

## Общий доступ через Expose

В настройках появился раздел «Общий доступ»: локальные сайты можно публиковать в интернете через защищённый туннель [Expose](https://expose.dev) — для вебхуков, демо заказчику или проверки сайта с телефона. Интеграция нативная, для начала хватит бесплатного тарифа. Поделиться сайтом также можно одной кнопкой из Herd Studio или командой `herd share`.

## Возможности бесплатной версии

### Запуск нескольких версий Node.js

Herd поставляется с nvm, менеджером версий Node, позволяющим вам легко управлять версиями Node.js на вашей машине.

Вы можете устанавливать и переключаться между версиями за считанные секунды с помощью терминала или пользовательского интерфейса Herd.

### Удобное управление несколькими версиями PHP

Herd поставляется с PHP 7.4 - 8.6, и вы можете переключаться между этими версиями в считанные секунды. Herd даже позволяет привязывать сайты к определённым версиям PHP.

Herd поддерживает все ваши установки PHP в актуальном состоянии и своевременно уведомляет вас о новых обновлениях.

![Управление версиями PHP](php_versions.png#only-light)
![Управление версиями PHP](php_versions_dark.png#only-dark)

Herd сам добавит нужные записи в переменные окружения, поэтому и Node.js, и PHP будут доступны глобально.

### Работа через консоль

Если вам лень каждый раз запускать графический интерфейс, всегда можно ограничиться командами в консоли. Например:

```sh
herd php -v # Просмотр текущей версии PHP

herd use 8.5 # Переключаемся на PHP 8.5

herd ini # Открыть php.ini для редактирования
```

См. [Полный список команд](https://herd.laravel.com/docs/windows/advanced-usage/command-line).

### Отладка с помощью Xdebug

=== ":material-microsoft-windows: Windows"

    Для работы с Xdebug достаточно добавить в конфигурационный файл `C:\Users\<Имя пользователя>\.config\herd\bin\<версия PHP>\php.ini` следующие строчки:

    ```ini
    ; Пример для PHP 8.5
    zend_extension=C:\Program Files\Herd\resources\app.asar.unpacked\resources\bin\xdebug\xdebug-8.5.dll

    ; Пример конфигурации для тестирования с покрытием
    xdebug.mode="coverage"
    xdebug.start_with_request=yes
    xdebug.start_upon_error=yes
    ```

=== ":simple-macos: MacOS"

    См. статью [Installing Xdebug with Laravel Herd](https://laravel-news.com/xdebug-laravel-herd)

После этого перезапустите сервисы Herd, откройте консоль и проверьте с помощью `php -v`, что поддержка Xdebug включена.

### Отладка с помощью PHP Debugger

Если Xdebug кажется вам слишком медленным, попробуйте расширение [PHP Debugger](https://github.com/pronskiy/php-debugger):

- загрузите *.dll файл в директорию `C:\Users\<Имя_пользователя>\.config\herd\bin\php85\ext` (поменяйте на свой путь и свою версию PHP)
- переименуйте в `php_debugger.dll` и добавьте строчку `zend_extension=php_debugger` в ваш `php.ini`

PHP Debugger поддерживает все те же опции, что и Xdebug, но не поддерживает покрытие кода, трассировку и профилирование. Поэтому он не такой тормозной. Для тестов покрытия можно отдельно установить [расширение `pcov`](https://github.com/OSPanel/php-windows-builder/releases?q=pcov&expanded=true), а затем добавить в `php.ini`:

```ini
extension=pcov

pcov.enabled = 1
```

??? note "Возможности Herd Pro"

    Всё необходимое для работы с Laravel предоставляется бесплатно. А для тех, кто хочет большего, есть подписка Herd Pro — €99 в год (для команды из десяти разработчиков — €299 в год, действует 14-дневная гарантия возврата). Купить или активировать лицензию можно на вкладке «Herd Pro» в настройках.

    * **Сервисы в один клик**

        Herd создаёт и управляет локальными сервисами: MySQL, PostgreSQL, MongoDB, Redis, Valkey, Meilisearch, Typesense, MinIO, RustFS и Laravel Reverb. Версии запускаются параллельно, значения для `.env` копируются из интерфейса, а в Herd 2.0 сервисы назначаются каждому сайту отдельно — приложение само подключится к нужной базе.

    * **Отладка**

        Herd Pro предоставляет вам мощный интерфейс для просмотра и сбора отладочной информации.

        Все вызовы `dump()` и `dd()` вашего приложения будут красиво отформатированы и могут быть отфильтрованы в отдельном окне Dump в Herd. В редакторе Insights помимо дампов доступны запросы к базе, логи, задания и HTTP-запросы — те же данные можно передать ИИ-агенту в Herd Studio.

    * **Почта**

        Встроенный локальный почтовый сервер складывает письма по отдельным ящикам для каждого приложения — тестировать и отлаживать рассылки стало проще.

    * **Tinker**

        Запуск PHP-сниппетов в контексте приложения прямо из Herd Studio.

    * **Безболезненная интеграция с Xdebug**

        Мощная функция обнаружения Xdebug в Herd автоматически включает Xdebug, когда это необходимо.

        Сканируя рабочее пространство PHPStorm на наличие точек останова и отслеживая входящие запросы с помощью браузерного расширения Xdebug, вы можете быть уверены, что Xdebug будет доступен в нужный момент - и только тогда.

    * **Контекст выполнения для агентов**

        ИИ-агенты получают доступ к запросам, логам, заданиям, дампам и HTTP-вызовам вашего приложения — им не придётся гадать, что происходит в коде.

## Доступ к базам данных

Laravel поддерживает SQLite, с хранением базы данных прямо в директории проекта. Так что ставить что-то отдельно не обязательно. Если нужны другие движки, есть инсталляторы [PostgreSQL](https://www.postgresql.org/download/windows/) (со встроенным приложением pgAdmin) и [MariaDB](https://mariadb.com/downloads/) для Windows. Либо можно воспользоваться сервисами Herd Pro, которые ставятся и запускаются прямо из приложения (см. блок выше).

!!! tip "Совет"

    Можно установить [OS Panel](../vozmozhnosti-open-server-panel-6), включить и настроить там только базу данных, например, MySQL, а затем подключиться к ней, просто указав соответствующий хост (типа `MySQL-8.0`) в настройках вашего проекта или отдельного приложения для доступа к базам данных.

В остальных случаях, поскольку доступ к сервисам возможен только в версии PRO, покупать которую не у всех найдётся желание (или возможность), устанавливайте движки баз данных отдельно, и используйте бесплатные приложения для работы с базами данных. Например, для MacOS есть такая крутая штука, как [DBngin](https://dbngin.com), а для Windows — [HeidiSQL](https://www.heidisql.com/download.php) и [DBeaver](https://dbeaver.io/download/). Наконец, есть ведь ещё и встроенные возможности некоторых IDE для подключения к базам данных.

![Пример интерфейса DBngin](dbngin.png#only-light)
![Пример интерфейса DBngin](dbngin_dark.png#only-dark)

В качестве альтернативы можно просто установить на один из сайтов Adminer или PHPMyAdmin с нужными для них версиями PHP.

Сравним возможности бесплатной версии Herd с другими известными продуктами:

| Фича / Приложение                   | Herd            | Docker | FlyEnv  | Open Server 6  |
| ----------------------------------- | --------------- | ------ | ------- | -------------- |
