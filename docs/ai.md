# ИИ

Список ресурсов для разработки с помощью ИИ.

---

## ❌ Обходить стороной

| Ресурс | Особенности |
| :--- | :--- |
| [CodeCraft](https://codecraftapi.com) | Старые модели, не работают переключение тем и удаление аккаунта |
| [CleanAPIs](https://cleanapis.com) | Старые модели, не работают переключение тем и удаление аккаунта |
| [Apinex](https://apinex.bond) | Токены уходят подозрительно быстро, модели тупят |
| [Hcnsec](https://api.hcnsec.cn/sign-up?aff=Pw47) | Дарят средства на баланс каждые сутки, нестабильный доступ к моделям (как и на похожих сайтах) |

## 🧪 Готовы рискнуть?

| Ресурс | Особенности |
| :--- | :--- |
| [TokenHarbor](https://tokenharbor.ai/) | Есть бесплатный тариф и модели, но ваши данные используются для обучения; за 1-2 бакса можно перейти на тариф повыше, где будет предоставлен Agent Pass |
| [Sharrowkin Dev](https://www.sharrowkin.dev/apply?ref=BNHPYJN3) | Русскоязычная IDE с множеством популярных моделей, но пока в разработке и иногда глючит |
| [Experiential Labs](https://platform.experientiallabs.ai/models) | Бывают бесплатные или скидочные предложения на ограниченный срок, тест новинок и т. д. |
